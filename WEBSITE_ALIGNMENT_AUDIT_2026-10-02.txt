GOVERNEDLOGIC.COM — GL / GI ALIGNMENT AUDIT
Date: 2026-10-02
Basis: Paul’s six mobile screenshots from the current production experience; current main homepage source (index.html, assets/launch.css, assets/launch.js); current canonical Governed Logic / Governed Intelligence source material; Governed Logic Business Strategy Addendum; On the Nature of Ultimate Grounding source state.

PURPOSE

Document every observed failure, contradiction, or material misalignment in the current homepage experience relative to Governed Logic (GL), Governed Intelligence (GI), the company truth set, and the stated requirement that human-readable and machine-readable representations correspond.

This is a QA / alignment record. It does not create new doctrine or rewrite Paul’s canonical work.

============================================================
A. CRITICAL SEMANTIC / CORRESPONDENCE FAILURES
============================================================

A1. OBLIGATION IS PRESENT IN THE DOM BUT NOT HUMAN-READABLE
Severity: CRITICAL

Observed:
The first-principles screen visibly presents:
BEING
TRUTH
LOGIC
MEANING
INTELLIGIBILITY
then a fluorescent gradient rectangle.

“OBLIGATION” is not human-readable in the screenshots.

Source:
index.html contains <span class="shine">OBLIGATION</span>.

Failure:
The machine representation contains six principles while the human representation visually exposes only five. This is a direct human/machine correspondence failure.

GL / GI alignment:
The constitutive set is Being, Truth, Logic, Meaning, Intelligibility, Obligation. A presentation that visually drops Obligation changes the represented architecture even though the source string survives in HTML.

Likely mechanism:
The .shine treatment relies on transparent text plus background-clip:text. In the tested mobile rendering path, the gradient is painting as a rectangular block rather than clipping to glyphs.

Required disposition:
BLOCKER. No semantic word may depend on a text effect that can erase the human-readable representation.

B. FIRST-PRINCIPLES / CONSTITUTIVE-PRINCIPLES FAILURES
============================================================

B1. HUMAN VIEW SHOWS FIVE PRINCIPLES, NOT SIX
Severity: CRITICAL
Cause: A1 plus mobile layout clipping.

The screenshots make the homepage appear to define only five principles. This is not merely a cosmetic omission because the six-principle set is constitutive to current GL/GI architecture.

------------------------------------------------------------

B2. INTELLIGIBILITY OVERFLOWS / IS CROPPED ON MOBILE
Severity: HIGH

Observed:
“INTELLIGIBILITY” extends beyond the viewport and is visibly cut off in the supplied screenshots.

Failure:
A constitutive principle is not fully readable on the target mobile viewport.

GL alignment:
A principle cannot function as a stable public semantic node if the interface truncates its representation.

------------------------------------------------------------

B3. PRINCIPLES ARE GIVEN UNEQUAL VISUAL ONTOLOGICAL WEIGHT WITHOUT A SOURCE BASIS
Severity: HIGH

Observed:
BEING / LOGIC / MEANING are filled.
TRUTH / INTELLIGIBILITY are outline-only.
OBLIGATION is currently converted into a gradient block.

Failure:
The visual system implies a hierarchy or difference in status among the six principles that the canonical architecture does not establish.

GL alignment:
The six are constitutive features of one reality. Decorative differentiation must not accidentally imply that some are primary, secondary, hollow, unresolved, or merely stylistic.

Required disposition:
Either make the visual distinction semantically justified from source or give the six equal legibility/status.

------------------------------------------------------------

B4. “FIRST PRINCIPLES” VS. CURRENT SETTLED “CONSTITUTIVE” LANGUAGE
Severity: MEDIUM / TERMINOLOGY CHECK

Observed:
Homepage label: “GOVERNED LOGIC · FIRST PRINCIPLES.”

Canonical direction:
Current GL/GI sources repeatedly describe the six as constitutive principles / constitutive features of one reality. Some project artifacts also use “first principles.”

Failure risk:
“First principles” may be acceptable historical shorthand, but it is weaker than the current constitutive claim. If the homepage is intended to state the settled architecture, the label should be checked against the newest canonical wording rather than inherited by convenience.

Disposition:
CHECK / DO NOT SILENTLY DECIDE.

============================================================
K. CORE ALIGNMENT TEST
============================================================

For every public visual or sentence, ask:

1. What representation is being shown?
2. What does it refer to?
3. Does the human receive the same meaning the source/machine receives?
4. Is the representation true to the canonical referent?
5. Does the design clarify the reasoning architecture, or merely imitate the appearance of intelligence?
6. Does the page make the company, Governed Logic, and Governed Intelligence more intelligible?
7. If the visual is removed, is meaning lost? If not, it is atmosphere and must remain subordinate.
8. If the text effect fails, does the proposition remain readable? If not, the effect is not robust enough for canonical language.
