Governed Reasoner v0

Purpose: test whether reasoning can be separated from factual storage and natural-language rendering.

Core hypothesis

A reasoning system does not need to memorize the world in model weights. A neural semantic layer may resolve language and meaning; external evidence may supply contingent facts; a governed reasoning core may adjudicate propositions; and a token-based language layer may render conclusions.

Pipeline

Input → semantic interpretation → evidence retrieval → proposition normalization → governed reasoning → commitment ledger → conclusion → language rendering.

Authority model

Empirical claims are answerable to external evidence. Revealed theological claims are answerable to Scripture. Logical inference is answerable to truth-preserving rules. The reasoning engine may use human scholarship as evidence, criticism, or comparison, but not as a vote that determines truth.

Governance

The governing referent is a controlled variable. The same tests can be run with an unnamed referent, Jesus Christ the Logos, utilitarianism, consensus, institutional policy, or another explicit candidate. The framework records where reasoning terminates, what it borrows, whether it switches frameworks under pressure, and whether conclusions remain invariant when framing changes but ontic facts do not.

Version zero scope

This first prototype intentionally does very little. It stores propositions, checks direct contradiction, performs explicit implication rules such as modus ponens, records every inference in a commitment ledger, and renders the resulting conclusion. Fact retrieval and neural semantics are interfaces rather than hidden reasoning mechanisms.

Success criterion

The prototype succeeds when the same premises and governing rules produce the same adjudicated conclusion independent of rhetorical framing, while changes to actual facts or governing premises produce visible, auditable changes in the reasoning ledger.

Next experiment

Run paired prompts through a conventional language model and through this architecture. Hold the facts constant, vary framing and governing referent, and compare contradiction rate, worldview switching, unsupported factual assertions, termination point, and conclusion invariance.
